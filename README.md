# 📱 Mobile Application Development Project

Bu repository, **MOBILE APPLICATION DEVELOPMENT** dersi kapsamında geliştirilen mobil uygulama projesini içermektedir.

---

## 📌 Proje Hakkında

Bu proje, mobil platformlar için modern web teknolojileri ve konteynerleştirme altyapısı kullanılarak geliştirilecek bir mobil uygulama projesidir.

> **Not:** Uygulama konsepti ve nihai özellikleri şu an planlama/değerlendirme aşamasındadır. Uygulama detayları netleştiğinde bu doküman güncellenecektir.

---

## 🚀 Kullanılan Teknolojiler ve Araçlar

Proje geliştirme sürecinde aşağıdaki teknolojiler ve araçlar kullanılacaktır:

- **Frontend:**
  - **HTML5:** Semantik yapı ve sayfa düzeni
  - **CSS3:** Modern, duyarlı (responsive) mobil arayüz tasarımı
  - **JavaScript:** Dinamik ve etkileşimli kullanıcı deneyimi
- **Geliştirme & Asistan:**
  - **Antigravity:** AI destekli geliştirme ve proje yönetimi
- **Sürüm Kontrolü & İş Birliği:**
  - **Git & GitHub:** Versiyon kontrolü, kaynak kod yönetimi ve dokümantasyon
- **Konteynerleştirme & Dağıtım:**
  - **Docker:** Uygulamanın tutarlı ve taşınabilir ortamlarda çalıştırılması

## 🛠️ Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

### 1. Depoyu Klonlayın
```bash
git clone https://github.com/rumeysa478/application.git
cd application
```

### 2. Tarayıcıda Açın
Uygulama statik web teknolojileri (HTML/CSS/JS) içerdiğinde, `index.html` dosyasını doğrudan bir tarayıcıda veya yerel bir sunucu (ör. Live Server) ile açabilirsiniz.

### 3. Docker ile Çalıştırma *(Docker yapılandırması eklendiğinde)*
```bash
docker build -t mobile-app .
docker run -p 8080:80 mobile-app
```
